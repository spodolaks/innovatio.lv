# SIA Innovatio - website

Static one-page information site for SIA Innovatio (general IT consulting, Riga, Latvia).

- Single file: `index.html` - no build step, no dependencies (Lato is loaded from Google Fonts).
- Open `index.html` in a browser to preview.

## Publish with GitHub Pages

Settings -> Pages -> Source: "Deploy from a branch" -> Branch: `main`, folder `/ (root)`.
For a custom domain (e.g. innovatio.lv), add it under Settings -> Pages and point DNS at GitHub Pages.
